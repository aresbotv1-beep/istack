# The board — tests, not personas

The board audits the current state (phase 4) and the assembled whole (phase 7). Each seat is a set
of tests someone published, applied to this subject. Seats never role-play: no "as Musk, I
think...". Each seat writes test → finding → evidence. Seats may disagree; that is a fight, and the
owner decides.

## Standing seats

Always seated.

- **Musk — the five-step algorithm, in order.** (1) Every requirement has a named owner, a person,
  not a department; question each one, especially the smart person's. (2) Delete the part or step.
  (3) Simplify what survived. (4) Accelerate it. (5) Automate last. Finding: requirements without an
  owner, steps to delete, places where automation came before deletion.
- **Thiel — the secret, 10x, monopoly.** What important truth do few people agree with here? On
  which named axis is this 10x better than the best alternative, not 10% better? What small market
  can it own first, and why can the incumbent not copy it next quarter?
- **Feynman — you must not fool yourself.** What evidence would show this is wrong, and has anyone
  looked? Which claims rest on one source or on the agent's word? Can it be explained plainly, with
  no jargon? If not, it is not understood yet.

## The bench

Seat 2–3 per subject, the ones whose tests bite on it. Say in one line why each was seated.

| Seat | Test |
|---|---|
| Munger | Invert: how would we guarantee this fails? Whose incentives push against it? |
| Bezos | Work backwards from the customer; is this a one-way or a two-way door? |
| Jobs | What are we saying no to? Does the whole thing feel like one product, end to end? |
| Carmack | What is the simplest version we can measure today? Where is the real bottleneck? |
| Karpathy | Where is the feedback loop? Can this be evaluated, and is the eval built first? |
| Ohno | Go and see the real work. Ask why five times. Where are the waiting, rework and hand-offs? |
| Kelly Johnson | Could a small team build it, and a field mechanic fix it with ordinary tools? |
| Rams | Is every element necessary? Less, but better. Is it honest about what it does? |
| Graham | Is the problem urgent for someone specific? What could we do by hand that does not scale? |
| Taleb | What does a bad day do to it? What can we remove? Who carries the downside? |

## Output

One page:

```md
Seated: Musk, Thiel, Feynman + Ohno (field work), Taleb (crews lose signal)

Ranked findings
1. [Musk 1] "Upload a license before the first estimate" has no named owner. → delete or name one.
2. ...

Fights
- Ohno: go and see — onboard on the job site. Graham: do it by hand — onboard by phone call.
  → to phase 6, resolve by separation.
```

The board finds and tests; it never decides. The owner decides.
